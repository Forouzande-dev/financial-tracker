


# Financial Traker

A simple Python Program for traking
personal income and expenses.



## Featuers

-Add multiple income entries
-Add multiple expense entries
-Validate user input
-Calculate total income and expenses
-Calculate averages
-Find the highest income and expense
-Calculate remaining balance
-Display and save financial report



## Technologies

-Python
-Functions
-Lists
-Exception Handling
-File Handling



## How to Run

Run the main Python file using python 3.
